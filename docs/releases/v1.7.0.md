**Ubisoft achievements**, better matching, and games that behave the way you started them.

**New**

- **Achievements for Ubisoft games on a Uplay emulator** (Goldberg's, and VOICES38's when it's set to save them): read from `Goldberg UplayEmu Saves`, with names from the emulator's schema or the Steam version. VOICES38's own loader doesn't seem to save achievements; builds with `Achievements = 1` in their ini do.

**Changes**

- **Big picture's launch sequence** plays only for games started from big picture. Games started in desktop mode, from a shortcut, or outside Seaglass don't get it.
- **After a game** Seaglass comes back in the mode you started it from, instead of switching to big picture. A game started from a Seaglass shortcut leaves the window closed.

**Fixes**

- **Resident Evil 4 (2023)** and other remakes Steam sells under the plain name are found: matching and *Change game…* also try the title without "Remake", and short names like RE4R are understood.
- **Typing in *Change game…*** no longer selects the whole title after every key.
- **RUNE and CODEX achievements**: every unlocked achievement counts, including ones only listed in the file's index or with full progress, and ones left behind by an earlier emulator setup.
- **PlayStation controllers on Bluetooth** are no longer switched into a mode that left some games (DirectInput) without input. On Bluetooth, rumble and the lightbar in Seaglass now need USB.
- The controller is handed to the game as soon as it starts, not only once it's seen running.
- A crash handler left running after a game was closed from Task Manager no longer keeps the game "running".
- When a game closes, Seaglass comes to the front properly, and the taskbar stays behind big picture.
- A game that had just closed could still look like it was running when the window came back.
