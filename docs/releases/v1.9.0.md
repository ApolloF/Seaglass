**New**

- **Turn on Ubisoft achievements.** For a Ubisoft game on a Uplay emulator (VOICES38, Goldberg Uplay) whose ini has achievements off, the Achievements card now has a **Turn on** button. It sets `Achievements = 1` in the emulator's ini (or creates one), and keeps the old file as `<ini>.seaglass.bak`. The card then says to play the game; if a play still saves no achievements, the card goes away, and it comes back by itself once a file shows up.

**Changes**

- Games installed outside a store launcher are now called **external copies**: the *External* library in the sidebar, labels like *External · RUNE*, and the *Recognise external copies* setting. Your setting, a hidden *Unofficial* library and your library's labels carry over.
- The README has an *Intended use* section.
