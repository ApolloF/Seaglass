First preview: WaterLauncher finds the games on your PC and lists them in desktop mode.

**Finding games**

- Steam, Epic, GOG, EA, Ubisoft, Battle.net and Xbox (moddable `XboxGames` folders) installs.
- External copies: games set up with a Steam API emulator (such as Goldberg/GSE, SmartSteamEmu or an unsigned `steam_api` DLL) are recognised, and their Steam AppID is read from the emulator's own files.
- Games from repack installers, through their Windows installer entries, with the "Play …" shortcut used to find the right executable.
- GOG offline installers and DRM-free copies through their `goggame-*.info` file.
- Common game folders on every drive, plus any folders you add: every subfolder that looks like a game is one.
- Titles and Steam ids come from the Ludusavi game database (about 50,000 games, downloaded on first start and refreshed weekly). Uncertain matches wait in **Found on this PC** for you to check.
- Steam playtime and last-played dates are imported.
- New installs are picked up automatically: WaterLauncher watches Steam's and Epic's install records, your desktop and your game folders.

**Desktop mode**

- Cover grid that stays smooth with thousands of games, search (Ctrl+F), sorting and filters by source.
- Details panel with Play, favorite, rename, choose the program, hide, open folder, and how the game was found and identified.
- Controller mode per game (Auto, Native, Steam Input). It is stored now and takes effect in v0.4.
- Light and dark theme, following Windows by default.

Games without art get a generated placeholder; real art arrives in v0.2.

**Try it:** download `WaterLauncher.exe` and run it. It's portable; settings and the library live in `%APPDATA%\WaterLauncher`.
