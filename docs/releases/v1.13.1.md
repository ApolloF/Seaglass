**Fixes**

- **Console games started through another copy of the emulator now count playtime.** If a game's launch options run a script that starts the game in a different copy of RPCS3, Dolphin or Cemu (a figure portal's controller with its own RPCS3, say), Seaglass didn't see the game running: it stayed on Starting and counted no playtime. Seaglass now knows the emulator by its name, wherever it's installed. An emulator that was already open when you pressed Play still doesn't count.
