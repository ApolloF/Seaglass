Saves: WaterLauncher now works with [Syncer](https://github.com/ApolloF/syncer), so your saves are up to date before you play and backed up after.

Needs **Syncer 0.11 or newer**. Older versions show *Syncer needs an update*.

**Before a game starts**

- *Sync saves* asks Syncer to bring the game's saves up to date from your other PCs and waits for it (up to a minute).
- If a save has two versions (two PCs changed it), you're asked first: open Syncer to pick one, play anyway, or cancel.
- If another PC backed up a newer save that hasn't arrived yet, you can wait for it (up to 2.5 minutes), play anyway, or cancel.
- Nothing ever stops a game from starting unless you choose to. If syncing isn't finished in time, the step shows a warning and the game starts.

**After a game exits**

- *Back up saves* runs Syncer's backup right away, so the latest save is in Google Drive.

**Everywhere**

- Game details (desktop) and the game page (big picture) show the saves: *Synced · backed up 2 hours ago*, *2 versions of a save*, *Newer save on TV-PC*, *Not in Syncer*, with *Open Syncer*, or *Get Syncer* when it isn't installed.
- When Syncer's window isn't open, WaterLauncher starts it without a window (`Syncer.exe --api`), and it stops again a minute after use.
- WaterLauncher tells Syncer which games are installed and where, so Syncer can match saves to games with unusual install folders, such as repacks and other external copies.
- Both steps can be turned off in Settings, Big picture, *While playing*.

**Under the hood**

- Steam and game-database detection now comes from [gamekit](https://github.com/ApolloF/gamekit), shared with Syncer. A scan finds the same games as before.
- The connection to Syncer only accepts a Syncer running as your own Windows user.
