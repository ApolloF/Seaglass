**Fixes**

- Games no longer count as crashed when they exit with code -1 or are closed with Ctrl+C.
- A game whose process ID Windows reused, or a process list Windows failed to return, no longer ends or confuses a session.
- *Quit* on a game now works as long as at least one of its processes was ended.
- GOG achievements keep their names, icons and rarity when GOG doesn't answer.
- Achievement icons that failed to download while offline are downloaded again later.
- Opening a game's achievements no longer waits for another game's achievements to be looked up.
- Game details found online no longer overwrite a match or art you picked while they were loading.
- Store playtime and last played are kept on owned games after a scan, and a store's *owned* mark covers every installed copy of the game.
- Disconnecting a store removes its *owned* marks from every game.
- Signing in or out of Epic or GOG while the library refreshes no longer brings back the old account.
- Saving new files to the desktop no longer rescans the library unless they are shortcuts.
- A failed library save is logged and tried again.
- A controller's small stick drift no longer counts as input, and unplugging a pad releases a held D-pad direction.
- Big picture: search ignores typing while a sheet or quick access is open, and rows and lists keep their place when the library changes.
- Desktop: renaming with Escape or Enter no longer applies a second time, and *Sign in with GOG/Epic* only asks for the code if the sign-in page opened.
- Long release notes in the updater no longer end in a broken character.
